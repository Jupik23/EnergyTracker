# EnergyTracker — historical mix

Generated by the [`Update history`](../../actions/workflows/update-history.yml) workflow (daily, plus manual
backfills). Force-pushed as a single commit; do not edit by hand.

| Path                                  | Content                                                   |
| ------------------------------------- | --------------------------------------------------------- |
| `v1/history/index.json`               | Months available per country                              |
| `v1/history/<country>/<YYYY-MM>.json` | Hourly generation per fuel category, CO₂ and renewables   |
| `v1/history/<country>/daily.json`     | Daily averages for all months (calendar, seasonal charts) |

Schema: `packages/core/src/history.ts` on `main`. Data: Energy-Charts (Fraunhofer ISE, CC BY 4.0).
